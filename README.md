# ironharness

Агентские харнессы для I/O и прошивок. Два модуля в одном репозитории:

- **io-core** — безопасный I/O-слой для агентов: транспорты (serial / TCP / Modbus / файловая песочница),
  JSONL-журнал всех операций, реплеер, политики и квоты, верификация эффектов, MCP-сервер.
- **ironbench** — бенчмарк для firmware-агентов: золотые задачи в симуляторах (Wokwi ESP32/MicroPython,
  далее Renode), агентский цикл поверх LLM API, отчёты pass@k.
